# 研究室について（about.html）の写真

このフォルダに、下の表のファイル名で写真を入れると、「研究室のあゆみ」の各時期の横に表示されます。
写真が無い時期は、文章だけが表示されます。

- 形式：JPG（横長 16:10、1280×800px 程度、300KB 以下を推奨）。16:10 からはみ出す部分は上下または左右が切り取られます。
- 写真の説明は、about.html の該当する `<img … alt="">` の `alt` に書いてください（例：`alt="工学部2号館の実験室"`）。
