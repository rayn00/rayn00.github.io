# 研究室について（about.html）の写真

このフォルダに、下の表のファイル名で写真を入れると、「研究室のあゆみ」の各時期の横に表示されます（最後の「現在」は、今の研究室の写真です）。
写真が無い時期は、文章だけが表示されます。

- 形式：JPG（横幅 480px、100KB 以下を推奨。ページ上でも横幅 480px までで表示します）。縦横比はそのまま表示されます（切り取られません）。
- スマートフォンで撮った写真には撮影場所の位置情報（GPS）が入っていることがあります。縮小して位置情報を消してから置いてください（GitHub に一度上げたファイルは、差し替えても履歴に残ります）。
- 今入っている写真はすべて横幅 480px に縮小・圧縮し、位置情報などの付加情報を取り除いてあります（2020年度はフロア案内のVRセンターの部分、2023年度は人物が中心になるように切り抜き）。
- 写真の説明は、about.html の該当する `<img … alt="">` の `alt` に書いてください（例：`alt="工学部2号館の実験室"`）。
