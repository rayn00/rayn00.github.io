# 「ぶるなびの歩み」ページ（buru-navi.html）の写真

このフォルダに、下の表のファイル名で写真を入れると、buru-navi.html の各欄に表示されます。
写真が無いあいだは、「写真を入れる場所」という点線の枠が表示されます。系譜の各時代には、写真を2枚ずつ入れられます。

- 形式：JPG。開発チームと年表の写真は横長 4:3（960×720px 程度）、原理の図と「東京大学での発展」の各カードの写真は横長 16:9（960×540px 程度）、200KB 以下を推奨
- はみ出す部分は、上下または左右が切り取られて表示されます。
- 写真の下の説明と、読み上げ用の説明（`alt`・`data-alt-ja`・`data-alt-en`）は、写真の内容に合わせて buru-navi.html で書き換えてください。
- NTT在籍時の写真など、公開してよい写真（権利者の了承が取れているもの）だけを入れてください。

## 報道のスクリーンショット（`img/buru-navi/media/`）

「報道・紹介記事」の欄の、新聞・テレビ・雑誌の上に並ぶカード（区分ごとに4枚）に表示されます。Webニュースには画像を入れません。横長 16:10（800×500px 程度）、150KB 以下を推奨します。

- スクリーンショットや紙面・誌面の画像を載せるときは、あらかじめ権利者（新聞社・放送局・出版社など）の了承を得てください。クレジット表記だけでは、掲載の許諾にはなりません。
- 画像の下のクレジット（例：`© NHK`）は仮のものです。buru-navi.html の該当カードの `<p class="bn-credit">` を、権利者の指定する表記に書き換えてください。
- カードにする記事を入れ替えるときは、buru-navi.html の `<article class="bn-media-card">` 〜 `</article>` を書き換えます。カードの下の一覧（`<ol class="bn-press">`）には、すべての掲載を1行ずつ載せています。
