# ニュース記事（news/ フォルダの記事ページ）の写真

このフォルダに写真を入れ、記事のページ（`news/西暦-月-日-記事名.html`）の `<div class="article-photos">` の中に `<figure>` を書くと、記事の上部に表示されます（1つの記事に何枚でも載せられます）。
写真が無い記事では、写真の枠は表示されません。

- 形式：JPG（横幅 1200px 程度、300KB 以下を推奨）。縦長・横長どちらでもかまいません。
- PNG を使うときは、記事のページの `.jpg` を `.png` に書き換えてください。
- 写真の説明（`alt="受賞の写真"`）は、写真の内容に合わせて書き換えてください（例：`alt="賞状を手にする受賞者"`）。
