# ニュース記事（news.html のポップアップ）の写真

このフォルダに、下の表のファイル名で写真を入れると、ニュースの詳しい記事の上部に表示されます。
写真が無い記事では、写真の枠は表示されません。

- 形式：JPG（横幅 1200px 程度、300KB 以下を推奨）。縦長・横長どちらでもかまいません。
- PNG を使うときは、news.html の該当記事の `.jpg` を `.png` に書き換えてください。
- 写真の説明（`alt="受賞の写真"`）は、写真の内容に合わせて書き換えてください（例：`alt="賞状を手にする受賞者"`）。
