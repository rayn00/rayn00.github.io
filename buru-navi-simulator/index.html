03 / Understand

平均力と、
感じる力の違い。

ぶるなびの研究を見る
01

非対称なのは、加速度の波形。

短く強い反力と、長く弱い逆向きの反力を繰り返します。ここでは正弦波に第2高調波を加えて、その違いを表しました。単に「行きだけ速い」移動を描くモデルではありません。

02

物理的な平均力は、ゼロ。

内部のおもりが1周期で元の位置・速度に戻るため、反力の力積も1周期でゼロになります。画面では手で保持された筐体を固定し、内部質量の慣性による反力 F = −ma を示しています。

03

牽引感は、人の知覚を通して生じる。

ぶるなびは、非対称な振動によって一方向に引かれる感覚を生み出す装置です。実際の感じ方は波形・周波数・接触条件などに依存します。このページは原理の視覚教材で、知覚強度や牽引方向を予測するシミュレーターではありません。

計算モデルと表示について

この計算式の出典について：このページのために定義した教材用の調和波モデルです。特定の論文の数式を採用したものではありません。基本波と第2高調波を合成した変位を微分して速度・加速度を求め、筐体反力を F = −ma で計算しています。Research Notesの文献は牽引力錯覚の研究背景を示すもので、この式の出典や妥当性を示すものではありません。

θ = 2πft、方向 d = ±1、片振幅 A、質量 m、非対称性 r（0〜0.5）として、次の周期運動を計算します。Aはm、mはkgへ換算します。

x(t) = d A [cos θ + (r/4) cos 2θ − r/4]
v(t) = −d A (2πf) [sin θ + (r/2) sin 2θ]
a(t) = −d A (2πf)² [cos θ + r cos 2θ]
F_case(t) = −m a(t)

変位の範囲は常に −A〜+A、周期平均速度・加速度・反力は0です。変位の平均値は −dAr/4 ですが、ストロークの中心は0です。表示は筐体を固定した理想化であり、筐体・手のコンプライアンス、摩擦、共振、アクチュエーターの伝達特性は含みません。

破線は同じ振幅・質量・周波数で r=0 とした対称波形です。グラフの縦軸は設定に合わせて変わるため、条件間の強度は数値も比較してください。ピーク・力積は1周期4096点の中点則で数値計算します。波形の色は筐体への反力の符号を表します。

スロー再生と位相スライダーは表示時刻だけを変えます。実時間では画面の更新周期によるエイリアシングが起きるため、運動の観察にはスロー再生を使ってください。機構図は変位・力・加速度を見やすく拡大した模式図で、実寸や実機の構造ではありません。

CSVは1周期を1000区間に分けた1001点です。時間・位相・変位・速度・加速度・筐体反力・対称条件の反力をSI単位で出力します。最初と最後の行は同じ周期境界です。ブラウザ内で計算し、入力データは送信・保存しません。スマートフォンのバイブレーターや外部機器は駆動しません。

操作：Spaceで再生／一時停止（ボタンやスライダーの操作中を除く）、位相スライダーで任意位置を観察、「1コマ進む」で1/48周期進めます。タブが非表示になると停止します。
