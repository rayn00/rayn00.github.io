# View Delay Lab — 視点遅延体験

three.jsの3D空間をマウスやスマートフォンの姿勢で見回し、追加遅延 **0 / 50 / 100 / 200 ms** を比較するデモです。

## 研究室サイトへの配置

研究室サイト（AME LAB）のリポジトリ直下に、このフォルダを**`view-delay-lab`という名前のまま**置きます。公開URLは次のとおりです。

https://www.amelab.vr.u-tokyo.ac.jp/view-delay-lab/

```
（リポジトリ直下）
├─ index.html ほか研究室サイトのファイル
├─ assets/  img/  .nojekyll
└─ view-delay-lab/   ← このフォルダ
```

- ヘッダー・フッター・色・文字は研究室サイト共通の`../assets/css/style.css`と`../assets/js/main.js`を使っています。ライト／ダーク切替・日英切替（ヘッダーとフッターのみ）・アクセス解析もほかのページと共通です。
- このページ専用の見た目は`style.css`に、研究室サイトの色の変数を使って書いています。
- トップページなどからはリンクしていません。URLを直接案内してください。
- ビルドやnpm installは不要です。three.js 0.180.0を`vendor/`に同梱しています。

## 操作方法

- **PC**：シーン内でマウスを左右・上下に動かして見回します。
- **スマートフォン**：「端末の姿勢」→「端末の姿勢を有効にする」を押し、必要に応じてセンサーの利用を許可します。最初の姿勢が正面になります。
- **タッチ操作**：「マウス・タッチ」に切り替えて、シーン内をドラッグします。
- **追加遅延**：0 / 50 / 100 / 200 msを選択します。
- **正面の再設定**：リセットボタンまたはRキーを使います。
- **全画面**：シーン右上の全画面ボタンを押します。全画面中も下部ボタンで遅延を切り替えられます。
- **キーボード**：シーンにフォーカスした状態で矢印キーを使います。
- **グラフ**：直近4秒の左右の回転について、入力と表示を重ねて表示します。

スマートフォンの姿勢センサーにはHTTPSと対応ブラウザが必要です。GitHub PagesのHTTPS URLをSafariやChromeで直接開いてください。アプリ内ブラウザや埋め込み表示でセンサーを利用できない場合は、通常のブラウザで開くかタッチ操作を使ってください。端末の縦横を変えた場合は正面が再設定されます。

## ローカルで確認する

`index.html`のダブルクリック（file://）ではES Modulesが読み込めない場合があります。研究室サイトのリポジトリ直下（`view-delay-lab`の1つ上のフォルダ）で、Python 3の簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

PCのブラウザで http://localhost:8000/view-delay-lab/ を開きます。スマートフォンの姿勢センサーの確認には公開後のHTTPS URLを使用してください。

## 遅延の実装

入力イベントを受信したときの姿勢と`performance.now()`の時刻を履歴として保存します。各描画フレームでは、`現在時刻 − 設定遅延`までに受信した最新の姿勢をカメラに適用します。0 msは最新の入力を直接反映します。

減衰や平滑化を使った見かけの遅れではなく、時刻付きの入力履歴を用いたsample-and-hold方式です。遅延条件の切り替え時は履歴を維持し、正面の再設定・入力方法の切り替え時は履歴をリセットします。3Dオブジェクトは静止しており、カメラの向きだけが変わります。

設定値は**追加するソフトウェア遅延**です。端末のセンサー、イベント配送、描画フレーム、GPU、画面表示に由来する遅延は別に生じます。表示するFPSは描画ループの頻度で、実際のmotion-to-photon latencyの測定値ではありません。物理的な総遅延を保証する実験装置としては扱わないでください。

姿勢センサーのデータはページ内の一時的な履歴として使用し、アプリから外部へ送信したり永続保存したりしません。

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| index.html | ページ本体 |

| package.json | Node.jsでテストを実行するための設定 |

## 動作確認状況

Node.jsがある環境で、依存パッケージを追加せず次を実行できます。

```bash
npm test
```

0 / 50 / 100 / 200 msの反映時刻、入力時刻の不均一性、短い入力の保持、条件切り替え、リセット、履歴保持、姿勢の正規化、角度の折り返し、縦横の校正など12項目のテストを通過しています。

作成時の確認用ブラウザではWebGLが無効だったため、3D描画とスマートフォン実機の姿勢入力は未確認です。配布前にPCと対象のスマートフォンで確認してください。
