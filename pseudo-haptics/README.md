# AMELab — Pseudo-haptics Playground

マウスの動きと画面上の応答をずらして、疑似触覚の考え方を試す5つのブラウザデモです。AMELab（東京大学 雨宮研究室）の研究テーマに着想を得た説明用の教材です。論文中の実験条件を再現したり、特定の錯覚を保証したりするものではありません。

デモ本体は HTML / CSS / JavaScript と Canvas 2D だけで動きます。ビルド、npm install、サーバー処理は不要です。すべての図形はコードで描画しています（ページの文字・アイコンは研究室サイト共通の Google Fonts・Font Awesome を読み込みます）。

## 5つのデモ

| デモ | 操作 | 変更できる値 |
| --- | --- | --- |
| 遅れてくるカーソル | マウスを動かし、オレンジのカーソルで的をクリック | 追加遅延 0〜400ms。0 / 50 / 100 / 200msのプリセット |
| 抵抗を感じる領域 | 中央の帯を横切り、左右の的を交互にクリック | 領域内の表示移動量 / 入力移動量 0.20〜1.50 |
| 持ち上げが遅れるカップ | 押したまま上下にドラッグ | 遅延 0〜500ms、上昇時だけ遅らせる切替 |
| 視点が変える持ち上げ | 押したまま上下にドラッグ | 手の倍率 0.25〜1.50、視点の倍率 −0.50〜0.75 |
| 手の回転とアバター | 押したまま左右にドラッグ | 遅延 0〜500ms、回転倍率 0.50〜1.50 |

共通機能は、効果あり／なしの比較、入力ガイド、直近3秒の入力・表示グラフ、リセット、全画面表示です。マウスを推奨します。タッチ操作にも対応し、スマートフォンでは指を画面上で動かします。端末の姿勢センサーは使用しません。

## 研究室サイトへの配置

```
（リポジトリ直下）
├─ index.html ほか研究室サイトのファイル
├─ assets/  img/  .nojekyll
└─ pseudo-haptics/   ← このフォルダ
```

- ヘッダー・フッター・色・文字は研究室サイト共通の`../assets/css/style.css`と`../assets/js/main.js`を使っています。ライト／ダーク切替・日英切替（ヘッダーとフッターのみ）・アクセス解析（ページ閲覧数）もほかのページと共通です。
- このページ専用の見た目は`style.css`に、研究室サイトの色の変数を使って書いています。デモの描画領域は両テーマとも濃紺で、描画色は`app.js`の色の指定をサイトの配色（シアン・紫・濃紺）に合わせています。オレンジのカーソルと手・カップの色は元のままです。
- トップページなどからはリンクしていません。URLを直接案内してください。
- 研究室サイトの別フォルダ（例：`view-delay-lab/`）と同じく、1階層下に置く前提で`../`を使っています。

## ローカル実行

研究室サイトのリポジトリ直下（`pseudo-haptics`の1つ上のフォルダ）で次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/pseudo-haptics/` を開きます。ES Modulesを使うため、`index.html` をダブルクリックして `file://` で開く方法は使いません。

## 操作

- 「体験をはじめる」を押してから、デモ領域を操作します。
- デモ領域内ではOSのカーソルを隠し、効果を加えたカーソルや手を描画します。領域外では通常のカーソルに戻ります。
- 「なし（基準）」で追加遅延0ms、移動倍率1、視点移動0の条件と比較します。
- 領域にフォーカスがある間は、Spaceを押している間だけ基準条件になります。Rでリセット、Escで全画面を閉じる／体験を終了します。
- 矢印キーでも補助操作できます。カーソル課題はEnterで的を選択できます。
- 抵抗領域（デモ02）では、PCで画面内をクリックするとポインターロックを使い、マウスの移動量（`movementX` / `movementY`）で表示カーソルを動かします。画面端でも操作を続けられます。Escで解除し、もう一度クリックすると再開します。
- ポインターロックを使えない環境（埋め込み表示など）では、Shiftキーを押している間はマウスを動かしても表示カーソルが動かないので、マウスを戻して離せば続けられます。Escで解除した直後（約1秒）はブラウザがロックを受け付けないため、少し待ってからクリックしてください。
- タッチ操作では、指を離して置き直すと、表示カーソルの位置を保ったまま続けられます。
- タッチではカーソル課題もドラッグし、指を離した時点で的を選択します。
- 各デモのURL末尾は `#delay` / `#resistance` / `#cup` / `#viewpoint` / `#avatar` です。デモを選んだ状態のURLを共有できます。

## 遅延・倍率の実装

`engine.js` の `History` は入力イベントの受信時刻を `performance.now()` で記録し、描画時刻から指定遅延を引いた時刻以前の最新サンプルを採用します。未来のサンプルを使う補間や、追従を遅くする平滑化は行いません。受信した入力イベントを基準とする追加遅延です。0msでもマウス・OS・ブラウザ・ディスプレイの遅延はあります。

描画は `requestAnimationFrame` に同期します。追加遅延の反映は入力周期・描画周期で量子化されます。例えば描画が60Hzなら約16.7ms単位で更新されるため、正確な端末間の遅延比較や知覚閾値測定には別途校正が必要です。短い動きは低フレームレートでは見えない場合があります。画面下部にFPSを表示します。

抵抗領域は表示カーソルの位置で判定し、入力の移動量に倍率を掛けます。大きな入力イベントが帯の境界をまたぐ場合も、内外の区間を分割して計算します。マウスの物理的な移動量は計測していません。OSの加速設定などの影響を受けたブラウザ座標を入力とします。

「持ち上げだけ遅らせる」では下降時に `min(前フレームの表示高さ, 現在の入力高さ)` を使い、切り返しでカップが上に跳ぶことを防ぎます。そのため、下降に切り替えた直後は表示が一時停止する場合があります。動作全体が固定遅延になる条件とは異なります。オフにすると上下とも固定の追加遅延になります。

手と視点のデモは透視投影を自前で計算するCanvas 2D描画です。時間遅延は加えません。手の高さとカメラの高さを入力から独立に計算します。LIFTSは入力高さの往復回数です。アバターの手は実際の手首を追跡せず、水平ドラッグを回転角に対応付けています。

効果の切替・リセット・デモ選択時は履歴を初期化します。タブを非表示にすると体験を停止します。センサー、カメラ、入力の保存・送信は使用しません（研究室サイト共通のアクセス解析でページの閲覧数だけを計測します）。

## 研究との対応

デモ01・02は一般的な時間・空間の対応付けを説明する導入課題です。03〜05は次の研究テーマとの関係をページ内に記載しています。

- [AMELab 研究紹介](https://www.amelab.vr.u-tokyo.ac.jp/research.html)
- [AMELab 発表文献](https://www.amelab.vr.u-tokyo.ac.jp/publications.html)
- **ThickSip: Pseudo-Haptic Augmentation of Liquid Weight and Thickness in Perceived Mouthfeel** — [DOI: 10.1145/3795011.3795026](https://doi.org/10.1145/3795011.3795026)。デモ03は上昇・下降で視覚応答を変える教材で、飲用や口腔内の感覚を再現しません。
- **手と視点の移動操作による重さ知覚（IEEE ISMAR 2025）** — [DOI: 10.1109/ISMAR67309.2025.00058](https://doi.org/10.1109/ISMAR67309.2025.00058)。デモ04は頭部追跡やVR提示を行いません。
- **自己アバタの遅延とねじれの錯覚（Scientific Reports 2022）** — [DOI: 10.1038/s41598-022-10543-y](https://doi.org/10.1038/s41598-022-10543-y)。デモ05には腱への振動刺激がなく、論文の運動錯覚を再現するものではありません。

研究紹介・文献情報は2026年11月2日に確認しました。ページのシンボルは本デモのための図形で、研究室の公式ロゴを複製したものではありません。

## テストとファイル

Node.js 20以降で、依存パッケージのインストールなしに実行できます。

```sh
npm test
```

16項目のテストで、遅延の期限・不規則入力・履歴保持、抵抗領域の境界、上昇／下降、手と視点の独立性などを確認します。実行環境の表示遅延や、主観的な錯覚を測定するテストではありません。

- `index.html`：UIと説明
- `style.css`：このページ専用のスタイル（研究室サイトの共通スタイルに追加）
- `app.js`：入力、UI状態、描画（グラフの色は`style.css`の`--trace-*`から読み取り）
- `engine.js`：遅延・移動倍率の計算
- `tests/engine.test.mjs`：数値計算のテスト

デスクトップのブラウザで5つのシーン・切替・ドラッグを確認しています。スマートフォン実機では未確認です。
